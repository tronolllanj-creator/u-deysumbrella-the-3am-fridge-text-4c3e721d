This repository contains a program that writes one original funny 3am fridge text — a single text-message line from a smart fridge to its owner at 3am. The shipped line reads verbatim: "I hold your deepest kitchen secrets and right now your secret is a cold hot dog over the sink."

## Run it
```sh
node main.ts
```
